### Pre-requiste
- go to root directory folder
- npm install

### To Start All Application
- npm run start-all
(This will trigger json-server and vite concurrently) 
Note: To run one by one, 
    - npm run dev
    - npm run json-server

### To Run Unit Test
- npm run test

### To Run Cypress E2E Test
- npx cypress open
